# C# Практикум 

## Инструкция по запуску
1. Открыть решение в Visual Studio.
2. Нажать F5 (или Ctrl+F5) для запуска.
3. Выбрать нужный уровень и задание в консольном меню.

## Заметки по уровню 1
*   **Что было сложно:** Разобраться с выгрузкой проекта на GitHub, настройкой `.gitignore` (чтобы не заливались папки `bin` и `obj`). Понять, как правильно делать коммиты для каждого отдельного задания.
*   **Что узнал:** Вспомнил, как использовать массив `object[]` для вывода разных типов данных. Закрепил работу с `TryParse` для защиты программы от некорректного ввода. Научился реализовывать алгоритмы сортировки (пузырьком и вставками) и замерять их время через `Stopwatch`. Понял, как работает `Dictionary` для подсчета слов.
